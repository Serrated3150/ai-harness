# Changelog

All notable changes to ai-harness. Projects pin a version and upgrade with
`harness sync` (docs/VERSIONING.md).

## Unreleased

### Fixed

- **`sync` records the full commit SHA in the manifest.** `harness-check`
  fetches ai-harness by that exact commit to verify a sync PR, and a short SHA
  cannot be fetched.

## v1.0.0 — 2026-11-13

### Added

- **Routine contract** (`kit/contract/ROUTINES.md`). The generic rules
  extracted from The Dial Book: precedence, roster, hard limits, markers,
  claims, picking work, status and type labels, order of work and
  dependencies, the state snapshot, triage, the plan gate, implementation,
  follow-through, templates, run summary, the self-learning loop and
  extension. Every section has an anchor.
- **Nine base routines** (`kit/routines/`), generated by
  `tools/gen-routines.py`, plus the loader prompt.
- **Config-driven scripts**: `sections`, `lessons`, `state`, `gates`,
  `verify` and `review-prompt`, with `lib/config` and `lib/glob`.
- **Hook engine**, config-driven, that makes harness-owned files read-only.
- **Skills** `harness-gates`, `harness-pr`, `harness-review`,
  `harness-extend`, `harness-issue`, and the agent `harness-reviewer`.
- **Workflows** `harness-review`, `harness-state` and `harness-check`.
- **`tools/sync.mjs`**: install and upgrade by vendoring, with a sha256
  manifest, settings merge and `--init` templates.
- **Docs**: boundaries, adopting, extending, config, versioning and
  contributing.
